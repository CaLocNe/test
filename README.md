# Thư mục chứa file sách / bài học

Tải (upload) các file `.pdf` và `.doc`/`.docx` của bạn trực tiếp vào
thư mục này qua giao diện web của GitHub.

Sau khi upload xong, đường dẫn công khai của file sẽ là:

```
files/tên-file-của-bạn.pdf
```

Đây chính là giá trị bạn cần điền vào field `fileURL` khi thêm document
mới trong Firestore. Xem chi tiết trong `backend/schema.md` và
`HUONG_DAN.md` ở thư mục gốc.
